&#x20;**Scalable Web Application Deployment on AWS**



&#x20;**Project Overview**



This project demonstrates the deployment of a scalable and highly available web application infrastructure using Amazon Web Services (AWS). The infrastructure includes EC2 instances, Application Load Balancer (ALB), Auto Scaling Group (ASG), CloudWatch monitoring, and custom VPC networking components.



The project was designed to simulate a production-style cloud architecture with scalability, monitoring, fault tolerance, and load balancing capabilities.







&#x20;**AWS Services Used**



\* Amazon VPC

\* Public Subnets

\* Internet Gateway

\* Route Tables

\* Security Groups

\* Amazon EC2

\* Nginx Web Server

\* Application Load Balancer (ALB)

\* Target Group

\* Launch Template

\* Auto Scaling Group (ASG)

\* Amazon CloudWatch

\* IAM







&#x20;**Key Features**



\* Multi-AZ deployment architecture

\* Application Load Balancing

\* Auto Scaling based on CPU utilization

\* Health checks using Target Groups

\* CloudWatch monitoring and alarms

\* Scalable EC2 infrastructure

\* Secure networking using VPC and Security Groups
